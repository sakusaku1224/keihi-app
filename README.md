## どんなサービス？

## サービス概要
立替経費の申請・提出・承認の流れをひとつの画面で管理できるWebアプリです。領収書を添付するだけで金額や日付を自動で読み取ってくれるので、入力の手間が大幅に減ります。提出前には重複している明細をチェックする機能もあり、申請ミスを減らすことを目指します。また、申請のステータスを表示することで、提出漏れを防ぎます。
なお、実際の業務では出張日当や申請部門、細かい税区分など様々なルールがありますが、このアプリでは申請〜承認の基本的な流れに絞ってシンプルな構成にしています。

## 開発背景
普段の業務で使っている経費申請アプリが使いづらく、それを改善したいと思ったのがきっかけです。

具体的には、テーブルが画面に収まらず横スクロールが発生する・詳細が確認しづらい・入力は全て手打ちのため、インボイス番号や支払先の入力ではミスが起きやすいといった問題がありました。さらに申請のステータスが把握しづらく、下書きのまま提出を忘れてしまうこともよくありました。結果として「少額なら申請しなくてもいいか」と思ってしまうほどで、同じ悩みを持つ社員の声も聞いていました。
業務以外のところでなるべくストレスを感じたくない、そんな思いから開発するに至りました。

## 機能

**ダッシュボード**
- 下書き・提出済み・承認済みの件数をひと目で確認
- 今月の合計申請金額を表示
- 最近の申請一覧表示（申請日・金額・ステータス付き）

**申請一覧**
- ステータス・申請期間指定でフィルタリング
- ページネーション対応

**申請詳細**
- 明細一覧
- 明細詳細をトグルで展開
- 領収書画像・PDFのプレビュー

**申請作成**
- 手入力または領収書の自動読み取りで入力
- 領収書画像・PDFのアップロード対応
- カテゴリ・税率の選択

**セルフチェック**
- 同じ申請内の重複明細を検出
- 過去の申請との重複を検出
- 領収書が未添付の明細を警告

**ログイン**
- メールアドレス・パスワードでの認証
- ゲストログイン

## 使い方

1. トップページの「ゲストログイン」からすぐに試せます
2. 「新規申請」から申請を作成
3. 申請タイトルを入力、「明細を追加」からフォームモーダルに必要事項記入（手入力 or 領収書をアップロードしてOCR自動入力）
4. 提出前に内容を確認
5. 提出完了

## こだわりポイント
#### 「ちょっとしたストレスを減らす」を軸に

**① 明細入力モーダルを2カラム構成に**
- 左に入力フォーム、右に領収書プレビューを並べたレイアウト
- ドラッグ&ドロップでアップロードした領収書を見ながら入力・修正できるため、OCRの読み取り結果の確認や誤入力の修正がスムーズ
- PDF・画像どちらも対応しており、`content_type` で判定して表示方法を切り替えています

**② バリデーションエラーは「入力し始めたら」消える**
- `input` イベントで、入力を始めた瞬間に赤枠・エラーメッセージが消えるようにしました
- エラーが出た時点で多くのユーザーは何を直すべきか理解できると思います。入力の際にエラーが残り続けるより、速やかに消した方が良いと個人的に思っています。（エゴかもしれませんが、、、）
- 実装面では、422レスポンス時は `turbo:load` が発火しないため、`turbo:render` イベントも監視するよう対応しています

**③ セルフチェックは「過去の申請」も含めて重複チェック**
- 申請内の明細だけでなく、過去に提出・承認済みの申請の明細とも照合して重複を検知します
- 「同じ領収書を2回申請してしまった」というヒューマンエラーを未然に防ぐことを意識しました

**④ 提出確認画面はトグルで明細を展開**
- 明細の入力はモーダルで行うため、確認画面での見せ方を工夫しました
- トグルで明細を展開・折りたたみできる構成にすることで、一覧性と詳細確認を両立しています
